**Project Overview**
This project is a **Tourist Website** designed to showcase popular travel destinations, packages, and booking options. It provides users with an interactive and visually appealing platform to explore travel opportunities.
---
**Features**
*  Explore popular tourist destinations
*  Attractive travel packages
*  Search and navigation options
*  Fully responsive design (mobile-friendly)
*  Image galleries for locations
*  Contact / booking section

---
**Technologies Used**

* HTML5
* CSS3
* JavaScript
